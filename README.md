# Dr. Khalid Khan Zadran — Neurosurgery Website

A responsive website for Dr. Khalid Khan Zadran, consultant neurosurgeon in Kabul.

## Features

- English, Dari, and Pashto language support, including right-to-left layouts.
- Information about the doctor, specializations, qualifications, and common questions.
- Consultation requests prepared for WhatsApp.
- Automatic GitHub Pages deployment through GitHub Actions.

## Run locally

```bash
npm install
npm run dev
```

Build and preview the production site:

```bash
npm run build
npm run preview
```

## Deployment

Live site: [eiman16-edge.github.io/Healthcare-website](https://eiman16-edge.github.io/Healthcare-website/)

Push to `main` to deploy using `.github/workflows/deploy-pages.yml`.
